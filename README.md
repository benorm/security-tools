# Security Tools

보안 도구를 직접 구현하며 그 동작 원리를 학습하는 저장소입니다.
기성 도구에 의존하지 않고 패킷·프로토콜 레벨에서 직접 만들어 보며,
각 프로젝트에서 마주친 기술적 한계까지 분석·기록합니다.

## 프로젝트

| 프로젝트 | 설명 | 기술 |
|---------|------|------|
| [syn-scanner](./syn-scanner) | TCP SYN 스캔 기반 포트 스캐너 | Python, Scapy |

## 라이선스

각 프로젝트의 라이선스는 해당 폴더 및 최상위 [LICENSE](./LICENSE)를 참고하세요.
Scapy(GPL v2)를 사용하는 프로젝트가 포함되어 있어 저장소는 GPL v2를 따릅니다.

## 면책

이 저장소의 도구들은 학습 및 **본인 소유·허가받은 환경에서의 테스트**
목적으로만 사용해야 합니다. 허가 없는 사용은 법적 책임을 물을 수 있습니다.
